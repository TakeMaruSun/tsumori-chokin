# つもり貯金

**ガマンした分だけ、未来の推し活へ。**

ライブの抽選に外れた、遠征をやめた、グッズを我慢した……そのとき使うはずだったお金を「貯まったつもり」で記録するアプリです。
落選の悲しい気持ちを、ちょっと明るく考えられるように。

👉 https://oshi-tsumori.pages.dev/

## 使いかた

1. スマホで上の URL を開く
2. 「ホーム画面に追加」する（アプリのように開けて、電波がなくても使えます）
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー（︙）→「ホーム画面に追加」
3. 落選した日も、ガマンした日も、使うはずだった金額を記録する

## できること

- **ビン／ガチャガチャ**：記録するほどビンの中身が増えたり、ガチャガチャのカプセルが積もったりします。目標額に届くと棚に並び、次の入れものに切り替わります
- **用途ごとに分ける**：「遠征用」「グッズ用」のように入れものを分けられます（せっていでオン）
- **推しカラー**：画面の色を推しの色に変えられます
- **まとめ**：月ごとの推移、カテゴリ別、カレンダー、バッジ
- **バックアップ**：記録をファイルに書き出して、機種変更のときに移せます。CSV でも書き出せます

## 記録について（プライバシー）

- 入力した記録は、**その端末のブラウザの中だけ**に保存されます。どこにも送信されません
- アプリはブラウザのセキュリティ設定で、外部との通信そのものを禁止しています。アクセス解析や広告もありません
- 記録は端末ごと・ブラウザごとに別々です。機種変更のときは「せってい → バックアップを書き出す」で移してください

## 更新について

- アプリは**自動では更新されません**。「せってい → 更新を確認する」を押すと、変更内容を見てから更新するか選べます
- 更新したあとでも「前の版に戻す」で、記録ごと更新前に戻せます
- 画面がおかしくなったときは、https://oshi-tsumori.pages.dev/?reset を開くと、アプリを入れ直せます（記録は消えません）
